{%- comment -%} Table of contents for a post, built from its

headings. Not a minima file — ours. Usage: {%- include toc.html content=content -%} Built from the rendered HTML rather than a plugin, because GitHub Pages allows neither custom plugins nor kramdown's {:toc} without per-post markup. kramdown's auto_ids gives every heading an id already, so the anchors exist without any extra work. h3 is nested under its h2, but only when a post has 5 or fewer top-level sections. A post that already has many h2s does not need a second level to be findable, and showing one would hurt: the learning-path post has 9 h2s and 17 h3s, so a full listing there is 26 lines, longer than several of the sections it points at. Posts with fewer than 4 entries get nothing — a list of two or three items sitting above a short post is furniture, not navigation. {%- endcomment -%} {%- assign chunks = include.content | split: '

0 -%} {%- assign show_h3 = true -%} {%- assign entry_count = h2_count | plus: h3_count -%} {%- endif -%} {%- if entry_count >= 4 -%}
