{%- comment -%} Overrides minima 2.5.1's _includes/footer.html, which printed site.title three times: once as a heading, once in the contact list (site.author falls back to site.title), and once inside site.description. This is one line: name left, icon links right. The icons come from the theme's own assets/minima-social-icons.svg sprite, so no new asset is added. Those s carry no viewBox, so they only render correctly at their native 16x16 — .svg-icon must not resize them. The envelope is inline because the sprite has no mail icon; it is drawn on the same 16x16 grid so it matches. Icon-only links need an accessible name, hence aria-label on each. The h-card / u-url / p-name / u-email classes are microformats the theme sets up and jekyll-seo-tag pairs with; they are kept even though the markup around them changed. {%- endcomment -%}
{%- comment -%} footer-inner is its own element rather than a class on .wrapper: the theme's .wrapper carries a clearfix ::after, which would become a third flex item and take the right-hand slot that justify-content: space-between is meant to give the icons. {%- endcomment -%}
