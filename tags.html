--- layout: page title: Tags permalink: /tags/ description: "Every post on this site, grouped by tag." --- {%- comment -%} Built from site.tags, which Jekyll populates from post front matter. No plugin involved, so this works as-is on GitHub Pages (jekyll-archives does not). site.tags is a hash; `sort` turns it into [name, posts] pairs ordered by name. slugify: "raw" must match _includes/tag-list.html, or the anchors will not line up. `pin` is pulled out of that alphabetical run and rendered first, in the cloud and in the sections below. Left in place it would sort between `llm` and `reproducibility`, where a tag that means "start with these" reads as an accident. It is skipped in the main loop so it is not listed twice. {%- endcomment -%} {%- assign tags = site.tags | sort -%} {%- assign pinned = site.tags.pin -%}
